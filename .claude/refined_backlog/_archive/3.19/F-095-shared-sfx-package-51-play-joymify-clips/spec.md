# I-106 — Shared SFX package `@montionugera/joy-sfx`

Owner decision (2026-11-09): move all 51 SFX clips from play-joymify into joy-design so every Joymify app
reuses one set, including the 7 ElevenLabs takes (owner accepts the licence follow-up).

## Source
- Files: `~/workspace/repos/play-joymify/web/public/audio/sfx/*.mp3` (51 files, 676 KB, mono 96 kbps, peak -12 dBFS).
- Provenance table and processing notes: `~/workspace/repos/play-joymify/web/art/audio/README.md`
  (24 Mixkit/Pixabay, 7 ElevenLabs, 20 `emote_*` ElevenLabs).
- Names: `SfxName` union in `~/workspace/repos/play-joymify/web/src/lib/sfx/sfx.ts`.

## Shape (mirror `packages/mascots`)
- `packages/sfx/assets/<name>.mp3` copied byte-for-byte.
- `packages/sfx/src/manifest.json` + `manifest.d.ts`: one entry per clip `{ name, file, durationMs, source, licence, title }`
  generated by `scripts/build-manifest.mjs` from the files and the provenance table (durations measured with ffprobe).
- `packages/sfx/src/index.ts`: `SFX_NAMES`, `SfxName`, `sfxUrl(name)`, and `createSfxPlayer({ baseUrl?, enabled?, reducedMotion? })`
  returning `{ play(name, { gain? }), setEnabled, unlock }` on Web Audio with a hard limiter at -12 dB; never throws when
  AudioContext is unavailable. No framework dependency; Svelte/React apps wire it to `SoundController`.
- `packages/sfx/PROVENANCE.md` in the mascots style: what it is, where each clip came from, the ElevenLabs and
  Mixkit/Pixabay licence terms with the owner's open follow-up on ElevenLabs commercial terms.
- Package metadata, `files`, `exports`, `publishConfig` as in `packages/mascots/package.json`.
- Publish wiring: add `sfx` wherever `publish.yml`, `scripts/integration.sh` and `scripts/test/consumer-smoke.sh` enumerate
  `tokens icons brand react svelte mascots`, with a smoke check that a consumer can import `SFX_NAMES` and resolve `sfxUrl('win')`.
- README.md: package table row + one usage section; DESIGN.md unchanged.

## Out of scope
Music loops (24 MB, Flow licence unconfirmed), new downloads from free libraries, Joy-Quest wiring (separate Joy-Quest feature).

## Acceptance criteria
- [ ] `packages/sfx/assets` holds exactly 51 `.mp3` files whose sha256 match the play-joymify sources.
- [ ] `node scripts/build-manifest.mjs` is idempotent and `manifest.json` has 51 entries, every one with source, licence and durationMs > 0.
- [ ] `pnpm --filter @montionugera/joy-sfx test` passes: manifest/file parity, `sfxUrl`, player no-throw without AudioContext, limiter present.
- [ ] `scripts/test/consumer-smoke.sh` packs and installs `joy-sfx` alongside the other six packages and resolves `sfxUrl('win')`.
- [ ] `publish.yml`, `integration.sh`, `consumer-smoke.sh` and README list `sfx` with the other packages; `pnpm check && pnpm lint && pnpm test` green.
- [ ] `PROVENANCE.md` lists every clip's source and the ElevenLabs follow-up.
