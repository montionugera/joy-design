## Summary
Files audited: 35 React components in packages/react/src (21 interactive/form components and 14 landing suite components), corresponding CSS in packages/tokens/build.js and dist/theme.css, and twin implementations in packages/svelte/src/lib.
Issue count by severity: 165 issues total (P0: 14 blocks production / P1: 144 visibly sloppy / P2: 7 polish).
Verdict: Fails production grade in both the product and brand registers due to critical light-mode contrast failures (invisible secondary hero CTA at 1.00:1), pervasive Tailwind slate/purple fallback pollution, 188px mobile viewport overflow at 375px in LandingPage, widespread class name invention missing from theme.css, and acute Svelte–React API parity divergences.

## Systemic patterns
- **CSS class name invention without theme stylesheet coverage**: React components reference numerous BEM modifier classes and helper utilities (e.g. .joy-button--, .joy-button__spinner, .joy-input-number--disabled, .joy-switch__label, .joy-form-label-width, .joy-hero__secondary-cta, .joy-landing-header) that have zero CSS rules in theme.css or build.js, rendering controls unstyled or broken.
- **Leaked kinetic dark-mode CSS to light mode hero CTA**: .joy-hero .joy-button--outline copies dark kinetic overlay styles (color: #f8f3e8 on background: #f8f3e8), resulting in a complete 1.00:1 contrast washout where secondary CTA text vanishes on standard light canvas.
- **Foreign palette pollution across fallbacks and dark mode**: Rather than adhering strictly to brand anchors (--navy-500: #14253e, --gold-400: #c49a3a, --cream-100: #f8f3e8, --ink-500: #1f1c13), components and build.js leak Tailwind slate (#1e293b, #334155, #64748b, #f8fafc) and purple (#7c3aed, #8b5cf6) into cards, borders, and badges.
- **Acute Svelte–React parity divergence**: React and Svelte twins diverge across multiple axes: props naming (camelCase onPrimaryClick vs lowercase onprimaryclick), class passing (className vs class), prop completeness (React Button and Input omit explicit standard attributes like disabled, value, type from their interfaces), and style architectures (React uses BEM while Svelte uses utility classes).
- **Mobile viewport clipping and overflow at 375px**: Fixed typography in hero/CTA titles (2.75rem / 2.25rem without clamp) causes institutional headings to overflow 375px mobile screens, while LandingPage renders a flex header row of ~515px that overflows the viewport by 188px with no mobile navigation drawer.
- **Violations of explicit AI-slop bans**: Components incorporate strictly banned patterns: gradient text (-webkit-background-clip: text with purple-to-gold), decorative glassmorphism (backdrop-filter: blur(8px)), middle-dot meta strings (&bull;), tracked uppercase eyebrows, and trailing arrows (→) appended to button and link labels.
- **Zero Emoji Policy violations**: Components including LandingPage, MarkdownEditor, Rate, and Upload render raw OS emojis (⚡, 🔒, 🚀, 📝, 👁️, 📁) instead of scalable vector SVG glyphs.
- **Uncalibrated gold and muted text contrast on light surfaces**: Brand gold #c49a3a produces only 2.36:1 contrast on cream and 2.62:1 on white, yet is deployed for text links, badges, and focus rings (rgba(196,154,58,0.35) fails WCAG 2.2 3:1 focus requirement).
- **Missing overlay behaviors for complex dropdowns**: Overlay components (TreeSelect, Cascader, DatePicker) do not use portals to escape overflow:hidden containers, lack Escape key handlers, and omit mobile sheet/drawer adaptations for coarse touch screens.
- **Missing touch target standards on mobile**: Small interactive controls (Segmented, Switch, Checkbox, close icons) provide sub-44px touch targets without compensating touch padding, failing WCAG 2.2 touch target sizing.
