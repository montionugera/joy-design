# Lint and type hygiene: svelte-check warnings, hub inline font sizes, check scripts Implementation Plan

Implemented on `feat/F-046` (commits c0f2615, aed03c1, 4fc46a1).

## 1. svelte-check warnings (21 before, 0 after)

Fixed at source:

- `Pagination`, `Anchor`: removed redundant `role="navigation"` on `<nav>`. `test/components.test.js`
  now asserts the native `<nav>` landmark instead of the literal attribute.
- `TimePicker`, `TreeSelect`, `Cascader`: combobox triggers get `aria-controls` pointing to a
  `$props.id()`-based panel id (set while open).
- `Mentions`: `role="combobox"` on the textarea, so its `aria-expanded`/`aria-controls` are valid.
- `Image`: `currentSrc` is a writable `$derived(src)` (overridden by the fallback on error) instead of
  `$state` + a syncing `$effect`.
- `MarkdownEditor`, `TreeSelect`, `Cascader`: one-time seeding of uncontrolled state from
  `defaultValue`/`mode`/`multiple` wrapped in `untrack()`; `bind:this` refs declared with `$state`.

Justified suppressions (verified false positives, each commented in source):

- `Tag`, `Image` — `a11y_no_noninteractive_tabindex`: the role is dynamic (`checkbox`/`button` only
  when interactive), and `tabindex=0` is set only in that case.
- `Select`, `Mentions`, `TreeSelect`, `Cascader` — `a11y_click_events_have_key_events` on options/items:
  the items are not focusable; the keyboard is handled by the owning combobox/panel
  (`aria-activedescendant` or roving focus, with Arrow/Enter/Space in `handleKeyDown`).

## 2. Hub font sizes (`apps/storybook-hub/build.js`)

22 literals replaced: `0.75rem` to `xs` (9), `0.875rem` to `sm` (11), `1rem` to `md` (1), `1.1rem` to `lg` (1;
equidistant between md and lg, lg keeps the stat emphasis).

Kept: the SVG logo `<text font-size="14">` attributes (10 occurrences, generated by
`scripts/gen-landing-blocks.mjs`). These are SVG user units inside a scaled `viewBox` artwork, not CSS
type, so no token applies.
