# Modern theme: Midnight Brass base, First Light gradient, Kintsugi seams

## Problem

Joy Design's default `:root` palette uses warm parchment cream (`#f8f3e8`), softer 6px/12px corners, and standard serif-accented brand cues, while I-108 research and prototyping established a sharper, cooler product aesthetic combining three approved directions:
- **Midnight Brass** for everyday surfaces and controls (cool porcelain `#F3F5F9` / `#FFFFFF` in light; deep midnight `#0A121F` / `#111B2B` in dark; sharp `3px` control and `4px` card corners; system UI typography; burnt-orange warning `#AD4A00` / `#F2884A` separated by >= 25 deg OKLCH hue from brass gold).
- **First Light (v3 dark-middle)** as the single 172 deg signature gradient (`#0B1226`, `#101B38`, `#2A2014`, `#4A2A14`, `#C7743F`, `#F2C078`) for call and brand-moment surfaces, keeping text (`#FBF3E9`) and the gold diamond mark (`#DAB362`) strictly on the dark upper end.
- **Kintsugi** two-facet gold seams (`#E0B03A` / `#AE7D0E` light, `#F0CC7A` / `#B8892B` dark) marking structural joins without competing with rows or card outlines.

Today those verified values live only in the I-108 specimen (`specimen/joy-combined-build.py` and `specimen/joy-combined-contrast.py`) and are unavailable through `@montionugera/joy-tokens`, Swift (`JoyDesign`), or Flutter (`joymify_flutter`). Replacing `:root` defaults directly would break existing consumers; instead, consumers need a non-breaking, opt-in `modern` preset.

## Why now

- The owner approved the merged Midnight Brass + First Light + Kintsugi direction and completed the specimen fix round (`b42cddd`), resolving seam visibility, warning-vs-brass hue separation, and gradient middle-band color transitions with 0 contrast failures (`lowest text contrast: 5.12:1`).
- Downstream native and web apps (starting with `joy-companion` and upcoming product surfaces) are ready to adopt the `modern` preset during `release/3.21` while leaving existing `classic` and `:root` apps completely unchanged.

## Design & Scope

Deliver `modern` as a non-breaking additive preset generated from a single source of truth (`packages/tokens/scripts/ramps.mjs` -> `packages/tokens/src/tokens.json`) across all token targets:

1. **Source Tokens (`packages/tokens/scripts/ramps.mjs` -> `tokens.json`)**:
   - Add `preset.modern` (`light` and `dark`) containing all Midnight Brass semantic surface, text, border, accent, brand, masthead, solid-action, live-indicator, and status colors, plus `radius-control: 3px`, `radius-card: 4px`, system `font-family-sans` / `font-family-ui`, First Light v3 172 deg gradient stops (`sky-1`..`sky-6`, `sky-text`, `sky-angle`, `sky-stops`, `gradient-first-light`, `gradient-first-light-srgb`), and Kintsugi seam tokens (`seam-a`, `seam-b`, `seam-width`, `seam-gradient`).
   - Keep all existing `:root`, `[data-theme="dark"]`, primitive ramps, and existing presets untouched.
2. **CSS & JS/TS (`packages/tokens/build.js` -> `dist/`)**:
   - Emit `[data-palette="modern"]` light, `[data-theme="dark"][data-palette="modern"]`, and `@media (prefers-color-scheme: dark)` blocks in `dist/theme.css`.
   - Export `presets` (including `presets.modern`) in `dist/index.js`, `dist/index.cjs`, and strongly typed interfaces in `dist/index.d.ts` (preserving `JoyTokens`, `JoyTokenName`, and all `@deprecated` alias annotations without introducing loose index signatures).
3. **Swift (`packages/tokens/scripts/gen-swift-tokens.mjs` -> `packages/swift/Sources/JoyDesign/JoyTokens.g.swift`)**:
   - Emit `JoyThemeTokens.modernLight`, `JoyThemeTokens.modernDark`, `JoyThemeTokens.modern(isDark:)`, and `JoyModernTokens` with all Midnight Brass, First Light gradient, Kintsugi seam, and 3px/4px radius tokens matching the exact specimen hex values.
4. **Flutter / Dart (`packages/tokens/scripts/gen-dart-tokens.mjs` -> `packages/flutter/lib/src/tokens/joy_tokens.g.dart`)**:
   - Add `JoyPalettePreset.modern`, `JoyThemeTokens.modernLight`, `JoyThemeTokens.modernDark`, `JoyThemeTokens.modern({bool isDark = false})`, and `JoyModernTokens`, updating `buildPreset` to resolve `status-*` overrides safely and ignore non-`JoyThemeTokens`-struct preset tokens cleanly.
5. **Verification & Docs Sync**:
   - Sync `DESIGN.md` / `README.md` via `node scripts/gen-design-md.mjs`.
   - Add/update contrast, token, Swift, and Flutter tests (`contrast.test.js`, `tokens.test.js`, `swift-tokens.test.js`, `JoyTokensTests.swift`, `tokens_test.dart`).
