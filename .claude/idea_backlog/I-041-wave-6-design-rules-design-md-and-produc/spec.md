# Wave 6: rules, docs and enforcement

Parent: E-001. Runs last so it documents what shipped. Inputs: `research/audit-standards.md`, `research/PRODUCT.draft.md`, the Wave 1 token model, the Wave 2–5 state matrices.

## Scope (in)

1. **`PRODUCT.md`** at repo root from the draft (register, users, purpose, personality, anti-references, principles, accessibility), corrected to match what shipped.
2. **`DESIGN.md`** at repo root in the Stitch DESIGN.md format generated from the real tokens: color system (primitive ramps + semantic layer in both themes with measured contrast), typography scale, spacing, radius roles, elevation, z-index, motion, component state matrix (per component: states × sizes), mobile rules, the ban list. Generated by a script `scripts/gen-design-md.mjs` from `tokens.json` so it cannot drift.
3. **`AGENTS.md`** rewrite of "Domain & Palette Invariants" into the token contract: semantic tokens only, no hex outside `tokens.json`, no fallbacks, the state matrix requirement, 44px touch targets, `prefers-reduced-motion`, Svelte/React parity, the AI-slop bans, the verification requirement (both themes, 375px and 1280px screenshots, contrast computed). Add a "Design skills" line pointing implementers at `impeccable`, `frontend-design`, `design-taste-frontend`.
4. **`README.md`**: architecture updated (semantic token layer, theme switching contract `data-theme` + `prefers-color-scheme`, Tailwind `@theme` import, consumer migration notes for deprecated aliases), gates section (`precheck.sh`, `lint-colors.sh`, contrast test, parity check, `epic-check.sh`, Playwright contracts), component inventory with framework parity badge, and a "What production-grade means here" checklist.
5. **Enforcement**: `lint-colors.sh` switches to strict for all packages and the hub; `precheck.sh` runs lint-colors, contrast test, parity check; add `pnpm check` scripts (`svelte-check` for `packages/svelte`, `tsc --noEmit` for `packages/react`) wired into turbo `check` and precheck, fixing any type errors they surface; `.github` workflow runs `pnpm check` and `scripts/precheck.sh`.
6. Remove the stale `plan.md` at repo root (F-031 leftovers) and point to `.claude/refined_backlog`.

## Acceptance criteria

- [ ] `scripts/precheck.sh` passes end to end with strict color lint; `pnpm check` passes.
- [ ] `DESIGN.md` regenerates byte-identically from `scripts/gen-design-md.mjs`.
- [ ] README renders the gate list and token contract; AGENTS.md has no reference to `--navy-500`-style raw variables as the contract (they are primitives, the contract is the semantic layer).
- [ ] CI workflow file references the new gates.
