## Summary
Files audited: 41 files in packages/svelte/src/lib (39 Svelte components: Alert, Anchor, Avatar, AvatarGroup, Badge, Breadcrumb, Divider, Drawer, Dropdown, EmptyState, Flex, Image, ImagePreview, MarkdownViewer, Menu, Message, MetricTile, Modal, Notification, Pagination, Popconfirm, Progress, Result, Skeleton, Space, Spin, Splitter, StatCard, Statistic, Steps, Table, Tabs, Tag, Timeline, Toast, Tooltip, BarChart, LineChart, CandlestickChart, plus chart-core.ts and overlay-utils.ts) along with corresponding CSS rules in packages/tokens/build.js.
Issue count by severity: 98 issues total (P0: 27 blocks production / P1: 67 visibly sloppy / P2: 4 polish).
Verdict: Fails production grade. The audited components exhibit critical dark-mode text invisibility (HUD badges rendering navy-on-navy at 1.00:1 contrast), hardcoded Tailwind slate/purple palette contamination, absolute violations of AI-slop bans (4px alert side-stripes, decorative backdrop glassmorphism, table hover purple tint #faf5ff), overlays that fail to trap focus or lock scroll, and uncalibrated mobile touch targets (< 44px).

## Systemic patterns
- **Navy text rendered on dark card/canvas surfaces (1.00:1 contrast)**: Multiple components (BarChart, LineChart, CandlestickChart HUDs, and Breadcrumb links) apply `color: var(--navy-500, #14253e)` without theme-sensitive remapping. In dark mode where canvas is `#0d1829` and cards are `#14253e`, text becomes 100% invisible (1.00:1 contrast).
- **Tailwind palette pollution instead of brand anchors**: Rather than deriving neutral and status colors from brand anchors (`--navy-500: #14253e`, `--gold-400: #c49a3a`, `--cream-100: #f8f3e8`, `--ink-500: #1f1c13`), components and fallbacks systematically inject Tailwind cool slates (`#0f172a`, `#1e293b`, `#334155`, `#64748b`, `#94a3b8`, `#cbd5e1`, `#e2e8f0`, `#f1f5f9`, `#f8fafc`) and banned purples (`#7c3aed`, `#faf5ff`).
- **Complete dark mode omission in component-level styles**: Several Svelte components with encapsulated `<style>` blocks (Alert, Badge, EmptyState, MetricTile) define zero `[data-theme="dark"]` overrides, causing light pastel backgrounds (`#eff6ff`, `#f0fdf4`, `#ffffff`) to flash at full luminance against dark app surfaces.
- **Direct violations of explicit AI-slop and style bans**: Alert enforces `border-left: 4px solid` (strictly banned side-stripe accent); Modal, Drawer, and ImagePreview enforce `backdrop-filter: blur()` (strictly banned decorative glassmorphism); Table hover enforces `background-color: #faf5ff` (unauthorized purple tint).
- **Uncoupled overlay accessibility primitives**: While `overlay-utils.ts` provides `lockBodyScroll` and `trapFocus`, neither `Modal.svelte`, `Drawer.svelte`, nor `Popconfirm.svelte` actually imports or utilizes them, allowing mobile background scrolling and focus escape.
- **Uncalibrated z-index scale**: Arbitrary magic numbers (`100` on Popconfirm, `1010` on Message/Notification, `1050`/`1060` on ImagePreview, `1200` on Toast) bypass tokenized scale, causing Popconfirm (100) to clip behind modals (1050) and dropdowns (1000).
- **Mobile touch target failure (< 44px)**: Pagination buttons (32x32px), Dropdown items (32px), Tabs (34px), and close buttons on Modal/Drawer/Toast violate the mandatory 44x44px mobile touch target standard on `<= 768px` viewports.
- **Missing prefers-reduced-motion across transitions and animations**: CSS keyframes and transitions in Spin, Skeleton shimmer, Progress, Table ticker flashes, Drawer slides, and Modal popups omit `@media (prefers-reduced-motion: reduce)`.
- **Keyboard inoperability in interactive data components**: Table column sorting and Splitter dragging lack `onkeydown` support, `tabindex="0"`, and ARIA state announcements (`aria-sort`, `aria-valuenow`).
- **Gold used on light surfaces failing WCAG AA**: Brand gold `#c49a3a` is repeatedly deployed for indicator balls (Anchor), step icons (Steps), and HUD text on white/cream backgrounds, yielding 2.36:1 to 2.62:1 contrast against the required 3:1 (UI) or 4.5:1 (text).
