server-decorator (ภาษาไทย)

เครื่องมือ Decorator ระดับ Production สำหรับ Caching, Tracking, Queue Emission และ Entity-Spec REST Generation รองรับ Node, Python, Go, Nim และ Rust ใน repository เดียว
เริ่มต้นใช้งานดูบน GitHub

ตัวอย่างโค้ดหลายภาษา (Polyglot)

หัวข้อที่มีชื่อว่า “ตัวอย่างโค้ดหลายภาษา (Polyglot)”

เลือกภาษาที่คุณต้องการเพียงครั้งเดียว โค้ดตัวอย่างในทุกหน้าของเอกสารจะเปลี่ยนเป็นภาษานั้นโดยอัตโนมัติ:

  • TypeScript / Node
  • Python
  • Go
  • Nim
  • Rust

จุดเด่นสำคัญ

หัวข้อที่มีชื่อว่า “จุดเด่นสำคัญ”

ขับเคลื่อนด้วย Contract

กำหนดโครงสร้างและข้อตกลงที่แน่นอนผ่าน JSON Schema ใน contracts/ ทำให้ทุกภาษามีพฤติกรรมสอดคล้องกัน 100%

ความถูกต้องระดับ Byte-Identical

EntitySpec IR และเอกสาร OpenAPI 3.1 ที่สร้างจาก Node, Python, Go, Nim และ Rust จะเหมือนกันทุกไบต์

ปลอดภัยสำหรับ Multi-Replica

อัลกอริทึมการแฮช Cache Key แบบ Canonical ป้องกันปัญหาข้อมูลแคชคลาดเคลื่อนข้ามระบบ

อัปเดตเวอร์ชันพร้อมกัน (Lockstep)

ทุกแพ็กเกจในทุกภาษาจะปล่อยเวอร์ชันเดียวกันพร้อมกันเสมอ ลดปัญหาความไม่เข้ากันของเวอร์ชัน
